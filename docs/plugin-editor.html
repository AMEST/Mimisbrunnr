ParamDefinitions, SharedCode and plugin API

ParamDefinitions is a JSON array of field descriptions. It replaces the obsolete Params list and drives labels, types, validation, groups and default values in the macro parameters dialog.

Supported types: text, textarea, code, json, number, boolean, select, date and attachment. Select fields require Options. Stored or inline values take precedence over DefaultValue, followed by legacy DefaultValues.

Definition fields: Name, Type, Label, Help, Rows, Pattern, Required, Advanced, Group, Options, DefaultValue.

[
  {
    "Name": "title",
    "Type": "text",
    "Label": "Title",
    "Help": "Shown above the content",
    "Required": true,
    "DefaultValue": "Untitled"
  },
  {
    "Name": "mode",
    "Type": "select",
    "Label": "Mode",
    "Options": ["view", "edit"],
    "DefaultValue": "view"
  }
]

SharedCode is JavaScript shared by the parameters dialog and the rendered macro. It runs before inline scripts and can expose helpers through MimisbrunnrPluginApi.helpers.

Macro scripts receive MimisbrunnrPluginApi with getParams(), getParam(name), setParam(name, value), save(), showToast(message, title, variant), openAttachmentPicker(callback), openEditor(url), getContext() and onParamsChanged(handler).

openAttachmentPicker(callback) returns a Promise with the selected file name or null on cancel. The optional callback receives the same result. onParamsChanged(handler) listens for changes to the current macro and returns an unsubscribe function.
